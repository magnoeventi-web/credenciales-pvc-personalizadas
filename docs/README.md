# Prioritas Creativo

Sitio web de presentación de Prioritas Creativo, enfocado en credenciales PVC personalizadas y tarjetas virtuales en Quito, Ecuador.

## Contenido del sitio

- Inicio con presentación del servicio y la imagen principal.
- Servicios de credenciales PVC, diseño gráfico y tarjetas virtuales.
- Precios por cantidad y por impresión de una o dos caras.
- Proceso de compra en cuatro pasos, con requisitos para enviar el diseño y condiciones de pago.
- Contacto y cotizaciones mediante WhatsApp.

## Estructura

- `index.html`: página principal; contiene la estructura, los estilos y el JavaScript del sitio.
- `img/hero.png`: imagen principal de la sección de inicio.

## Cómo visualizarlo

Abre `index.html` en un navegador. También puedes servir la carpeta con cualquier servidor web estático; no se requiere un proceso de compilación.

El sitio carga la fuente Inter desde Google Fonts, por lo que se necesita conexión a Internet para mostrarla.
